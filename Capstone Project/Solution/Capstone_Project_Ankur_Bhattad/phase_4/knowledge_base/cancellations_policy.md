# Cancellations Policy

## Cancellation window
- An order can be cancelled free of charge any time before it has shipped.
- Once an order has shipped, it can no longer be cancelled — the customer must wait for delivery
  and then use the standard return process instead.
- Cancellation status can be checked on the order history page; orders move from "Processing" to
  "Shipped" once handed to the carrier, after which cancellation is no longer available.

## Partial order cancellation
- For multi-item orders, individual items can be cancelled independently as long as that specific
  item has not yet shipped, even if other items in the same order have already shipped.
- Cancelling one item does not affect the shipping charge already applied to the rest of the
  order.

## Refunds for cancellations
- Cancelling before shipment results in a full refund, including any shipping charge paid, since
  no delivery took place.
- Cancellation refunds are issued to the original payment method within 5-7 business days,
  following the same timeline as return refunds.
