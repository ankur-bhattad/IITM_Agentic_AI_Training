# IITM Agentic AI Training

Repository for IITM Emeritus Course In Agentic AI Material

## 📚 Course Overview

This repository contains comprehensive learning materials, assignments, and projects for the IITM Emeritus Course in Agentic AI. The course is currently ongoing, with weekly resources, assignments, live session activities, and graded projects.

## 📁 Repository Structure

### 📖 Weekly Resources (`Weekly resources/`)
Curated learning materials for each week of the course. 
- Course Introduction & Fundamentals
- Weekly lecture materials and learning resources
- Specialized masterclass.

Each week contains notebooks, code samples, and reference materials to support the learning objectives.

### 📝 Assignments (`Assignments/`)
Weekly assignments designed to reinforce learning:
Assignments include hands-on coding exercises and problem-solving activities aligned with the weekly topics.

### 🎯 Graded Projects (`Graded Projects/`)
Comprehensive graded projects that assess learning outcomes.
These projects involve building end-to-end agentic AI solutions and require submission of working code and documentation.

### 💻 Live Session Activity (`Live Session Activity/`)
Interactive code and activity files from live sessions:
- Session-specific code and exercises
- Code from the retrieval masterclass

## 🔧 Technology Stack

The course primarily uses:
- **Jupyter Notebooks** (`.ipynb` files)
- **Python** for implementation
- **Agentic AI Frameworks** and libraries

## 📅 Current Progress

The course is on going. Materials are organized by week as they progress through the curriculum.

## 🎓 Learning Outcomes

By completing this course, you will:
- Understand the fundamentals of Agentic AI
- Build and deploy autonomous AI agents
- Implement retrieval-augmented generation (RAG) systems
- Design scalable agentic architectures
- Apply best practices in production environments

## 🚀 Getting Started

1. **Prerequisites**: Basic knowledge of Python and machine learning concepts
2. **Setup**: Clone this repository to access course materials
3. **Study Path**: Follow materials as they are released week by week
4. **Active Learning**: Complete assignments and projects alongside weekly materials

## 📚 File Format Guide

- **Jupyter Notebooks** (`.ipynb`): Interactive learning materials with code and explanations
- **Python Scripts** (`.py`): Reusable utility functions and helper code
- **Documentation**: README files and guides within subdirectories

## 💡 Tips for Success

1. **Keep Up with Weekly Releases**: Check back regularly for new materials each week
2. **Hands-on Practice**: Run notebooks and modify code to deepen understanding
3. **Project Completion**: Submit graded projects as assigned
4. **Masterclass Review**: Refer to the retrieval masterclass for advanced techniques
